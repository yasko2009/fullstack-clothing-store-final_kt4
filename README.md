# Clothing Store

Fullstack-веб-приложение интернет-магазина одежды.

# О проекте

Clothing Store — учебное fullstack-приложение для просмотра и управления товарами, авторизации пользователей и работы с корзиной.

Проект состоит из Frontend и Backend частей и реализует взаимодействие между ними через REST API.

# Технологии

# Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios
- Zustand

# Backend
- Node.js
- Express
- TypeScript
- JWT
- CORS
- dotenv

# Возможности

- просмотр каталога товаров;
- получение товаров через Backend API;
- добавление товаров;
- редактирование товаров;
- удаление товаров;
- добавление товаров в корзину;
- изменение количества товаров в корзине;
- удаление товаров из корзины;
- очистка корзины;
- автоматический расчёт общей стоимости;
- регистрация авторизации через JWT;
- защищённая страница профиля;
- выход из аккаунта;
- автоматическое добавление JWT в запросы через Axios Interceptor;
- адаптивный интерфейс для компьютеров и мобильных устройств.

# Clothing Store

Fullstack-веб-приложение интернет-магазина одежды.

# О проекте

Clothing Store — учебное fullstack-приложение для просмотра и управления товарами, авторизации пользователей и работы с корзиной.

Проект состоит из Frontend и Backend частей и реализует взаимодействие между ними через REST API.

# Backend API

Backend предоставляет REST API для работы с товарами и авторизацией пользователей.

## API маршруты

### Products

- `GET /api/products` — получение списка товаров;
- `GET /api/products/:id` — получение одного товара;
- `POST /api/products` — добавление товара;
- `PUT /api/products/:id` — редактирование товара;
- `DELETE /api/products/:id` — удаление товара.

### Authentication

- `POST /api/auth/login` — авторизация пользователя;
- `GET /api/profile` — получение профиля авторизованного пользователя.

# Авторизация

Для авторизации используется JWT.

После успешного входа Frontend сохраняет токен в `localStorage`.

Axios Interceptor автоматически добавляет JWT в запросы в формате:

`Authorization: Bearer <token>`

Маршрут `/profile` защищён компонентом `ProtectedRoute`.

Если токен отсутствует, пользователь автоматически перенаправляется на страницу входа.

При выходе из аккаунта токен и данные пользователя удаляются из `localStorage`.

# Обработка состояний интерфейса

В каталоге реализованы основные состояния приложения:

- `Loading` — отображается во время загрузки товаров;
- `Error` — отображается при ошибке запроса к Backend API;
- `Empty` — отображается, если API возвращает пустой список товаров.

# CRUD товаров

В приложении реализована работа с товарами через Backend API:

- получение списка товаров;
- получение одного товара;
- добавление нового товара;
- редактирование существующего товара;
- удаление товара.

После успешных операций состояние каталога автоматически обновляется через Zustand.
